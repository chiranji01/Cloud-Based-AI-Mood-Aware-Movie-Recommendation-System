This README documents only the work completed by me for the **Cloud-Based AI Mood-Aware Movie Recommendation System**.

## 2. My Contribution

I contributed to the frontend development of the project by:

## 3. Files I Worked On

### `src/pages/mood.jsx`

This file contains the React component for the Mood Selection page.

The component provides the user interface where users can select their current mood before continuing to the next stage of the movie recommendation system.

### `src/pages/mood.css`

This file contains the CSS styling for the Mood Selection page.

The styling is used to control:

* Page layout
* Mood selection buttons/cards
* Spacing and alignment
* Text styling
* Colours
* Fonts
* Hover and interaction effects
* Overall visual presentation

## 6. Running the Frontend

To run the frontend locally, open a terminal inside the `frontend` folder.

Run:

```bash
npm install
```

Then start the development server:

```bash
npm run dev
```

Vite will display a local development URL, normally similar to:

```text
http://localhost:5173/
```

Open the displayed URL in a web browser to access the application.

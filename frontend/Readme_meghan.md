# React Frontend Application

## Project Overview

This project is a React.js frontend application containing three main pages: **Login, Register, and Home**. It provides a simple and user-friendly interface with navigation between the pages.

## Features

* Login page
* Register page
* Home page
* Page navigation
* Form input handling
* Responsive UI

## Technologies Used

* React.js
* JavaScript
* CSS3
* React Router DOM
* Vite
* Node.js
* Git/GitHub

## Pages

* `/login` – User Login
* `/register` – User Registration
* `/home` – Home Page

## Installation

```bash
npm install
```

## Run the Project

```bash
npm run dev
```

The application will run at:

```text
http://localhost:5173/
```

## Project Status

The Login, Register, and Home pages have been completed with basic styling and navigation.

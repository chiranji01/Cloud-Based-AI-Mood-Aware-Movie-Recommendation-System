## Database and Backend API Development

I was responsible for the database and backend API component of the project. My work included designing the database structure using Django models and developing REST APIs to manage the movie dataset.

### Responsibilities

- Designed and implemented database models using Django's `models.py`.
- Developed RESTful APIs using Django REST Framework.
- Implemented CSV-to-MySQL data import functionality.
- Imported movie, rating, tag, and link datasets into the MySQL database.
- Created and managed Django migrations to maintain the database schema.
- Configured and integrated the Django backend with MySQL.
- Tested API endpoints for successful data storage and retrieval.

for this sprint I created an AWS EC2 instance and configured an Elastic IP for the project backend. The React Login and Register pages were also connected to Django authentication, allowing user registration and login details to be managed through Django’s AuthUser system.
